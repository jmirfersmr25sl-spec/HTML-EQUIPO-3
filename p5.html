P5 · Servicios de red

Instalación y configuración de servicios de red en el vivero

Configuración de una red interna con IP fija, DHCP, acceso remoto por RDP y un servidor FTP con acceso restringido por usuario.

Descargar el PDF

Paso a paso

12 pasos
01

Adaptadores de red

Configuramos el segundo adaptador de VirtualBox como red interna para conectar el servidor con nuestra red.

02

IP fija con Netplan

Asignamos la IP 192.168.1.10/24 a la red interna, aplicamos los cambios y comprobamos la dirección.

03

Instalar DHCP

Instalamos isc-dhcp-server para que el servidor reparta direcciones IP a los clientes.

04

Configurar DHCP

Definimos la red 192.168.1.0/24 con un rango de 192.168.1.100 a 192.168.1.200 y comprobamos que no hay errores.

05

Comprobar conectividad

Desde Ubuntu Desktop hacemos ping a 192.168.1.10 y recibimos cuatro respuestas sin pérdida de paquetes.

06

Escritorio remoto (XRDP)

Instalamos XRDP y comprobamos que el servicio está activo y preparado para recibir conexiones.

07

XFCE y Remmina

Configuramos XFCE como escritorio de la sesión e instalamos Remmina en Ubuntu Desktop para conectarnos por RDP.

08

Servidor FTP (vsftpd)

Instalamos vsftpd, hacemos una copia de seguridad de su configuración y permitimos el acceso de usuarios locales con escritura.

09

Crear usuarios

Creamos las cuentas iker, julenm, julenn y andrei con adduser y comprobamos que existen con getent passwd.

10

Carpetas y permisos

Creamos una carpeta personal privada para cada usuario y una carpeta común compartida con el grupo impri3d.

11

Aislamiento y montajes

Limitamos a cada usuario a su zona con chroot, enlazamos las carpetas con mount --bind y añadimos los montajes a /etc/fstab.

12

Pruebas de acceso

Comprobamos los permisos entre usuarios y nos conectamos por FTP desde Windows con iker y julenm.
