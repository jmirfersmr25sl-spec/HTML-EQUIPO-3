Instalación del equipamiento informático del vivero

Instalación de Windows Server 2019 en el servidor del vivero, con los roles de servidor web con FTP y DHCP, FileZilla Client y el gestor de contraseñas KeePassXC.

Descargar el PDF

Paso a paso

8 apartados
01

Material

Piezas y programas usados: placa MSI H81M-E33, procesador Intel Core i3-4160, 4 GB de RAM, disco Hitachi de 465,8 GB y Ventoy.

02

Configuración de la BIOS

Comprobamos que el equipo reconoce sus piezas y revisamos el orden de arranque desde Settings → Boot.

03

Instalación de Windows Server

Arrancamos desde el pendrive con Ventoy, elegimos Windows Server 2019 Standard Evaluation (Desktop Experience) e instalamos en el disco.

04

Configuración inicial

Establecemos la contraseña del usuario Administrador y entramos en el Administrador del servidor.

05

Roles y programas

Instalamos el servidor web (IIS) con FTP, el servidor DHCP, FileZilla Client y KeePassXC.

06

Medidas de seguridad

Las contraseñas se guardan en una base de datos de KeePassXC cifrada y protegida con una contraseña maestra.

07

Tiempos

Tiempo mínimo estimado para toda la práctica: 95 minutos (1 h 35 min).

08

Incidencias

KeePassXC no abría por falta del archivo MSVCP140.dll, solucionado con Visual C++. Queda pendiente fijar la IP del servidor.
