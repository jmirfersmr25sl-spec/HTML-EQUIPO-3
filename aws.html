P10 · Cloud computing

Despliegue de aplicaciones en AWS

Cómo lanzamos una instancia EC2 con Ubuntu y nos conectamos por SSH con MobaXterm.

VER PDF

Paso a paso

8 pasos
01

Esperar al laboratorio

Esperamos a que el botón del laboratorio de AWS Academy se ponga en verde.

02

Lanzar instancia

Entramos en EC2 y pulsamos «Lanzar instancia».

03

Nombre y sistema

Ponemos el nombre (Impri3d), elegimos Ubuntu y su versión.

04

Claves y firewall

Seleccionamos el par de claves, activamos el tráfico HTTP y HTTPS y lanzamos la instancia.

05

Revisar parámetros

Consultamos los datos de la instancia (IP pública, DNS) para usarlos en MobaXterm.

06

Sesión SSH

En MobaXterm: Session → SSH, IP pública y usuario ubuntu.

07

Clave privada

En ajustes avanzados marcamos «Use private key» y subimos el archivo .pem.

08

Actualizar el sistema

En la terminal ejecutamos apt update y apt upgrade -y.
